# Component credits

Plugin code uses forge-rs 1.5.0 by Fexty (MIT), the Forge API by Jeffi / the
Skyline Project, and MIT-licensed libnx ARM32 syscall code by the Hydrosphere
Developers. Sources: https://github.com/Fexty12573/forge-rs,
https://github.com/jeffi6375/forge and https://github.com/switchbrew/libnx.
The compiled plugin also includes log and Rust core/alloc/compiler-builtins
support. Applicable license texts follow in the combined notices.

The English common archive retains original Monster Hunter Generations Ultimate
resources by Capcom and HD resources from
[MHGU HD Project by Monkbreh / Monke](https://github.com/Monkbreh/MHGU-HD-Project).
The author's README describes upscaling with several ESRGAN models; exact models
and training datasets are not disclosed. Original game textures are its stated
inputs. This candidate creates no new artwork, extracts no emblem for delivery,
and adds no replacement atlas.
