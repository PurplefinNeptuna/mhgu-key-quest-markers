# Key Quest Markers

Adds `[KEY]` before progression key quest titles in quest lists and details,
including completed key quests.

## Requirements

MHGU 1.4.0 for Nintendo Switch and Forge.

## Installation

1. Close the emulator.
2. Extract `key-quest-markers-r2.zip`.
3. Copy the `key-quest-markers` folder into your MHGU mod directory:
   - Eden: `~/.local/share/eden/load/0100770008DD8000/`
   - Ryujinx: `mods/contents/0100770008dd8000/` inside its data directory.
4. Enable `key-quest-markers` in the emulator and launch the game.

Key quest markers appear automatically.
